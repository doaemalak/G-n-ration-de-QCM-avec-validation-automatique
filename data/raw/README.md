# Données brutes

Il faut déposer ici les 6 supports de cours PDF sur le langage C (voir le tableau du README principal) :

- `cours.pdf`
- `LelangageC_rgww.pdf`
- `cours_programmation_c.pdf`
- `annexe_08_2_cours_programmation en langage C.pdf`
- `coursC.pdf`
- `support-C-JacquelinCharbonnel.pdf`

Les PDF ne sont pas versionnés (`.gitignore`), car leurs auteurs en conservent les droits.

`sources.csv` est généré par le notebook (étapes 1 et 2). Il donne pour chaque cours : titre, auteur, format, nombre de pages, mots bruts, mots après nettoyage et part supprimée.
